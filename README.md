# Free Market

A static web project inspired by the interface and navigation structure of **Mercado Livre**, developed exclusively with pure **HTML5**. The main objective of this project is to practice semantic web page structuring, content organization, and internal navigation using only native HTML features.

## Features and Highlights

- **Product Display:** A structured product showcase utilizing images, hierarchical headings, and detailed descriptions.

- **Anchor Navigation (`<a href="#id">`):** Quick-jump links to navigate directly to specific sections of the page (such as categories, and daily deals).

- **Internal Links:** Seamless navigation across site pages and sections via standard hyperlinks (`<a href="...">`).

- **Enhanced Media Tags:** Properly structured media and captions using `<figure>` and `<figcaption>` elements.

## HTML Tags Used

- **`<h1>`, `<h2>`, `<h3>`:** Establishing clear heading hierarchy for SEO and web accessibility.

- **`<figure>`, `<figcaption>`:** Proper implementation of semantic image and caption markup.

- **`<a href="#id">`, `<a href="...">`:** Building clean user navigation flows using ID references and anchor links.

## Tech Stack

- **HTML5:** The sole technology used for markup, structure, and site navigation.

## Getting Started

Since this project was built using **HTML only**, there are no complex tools, build steps, or dependencies (like Node.js) required.

1. Clone or download this repository to your local machine:
```bash
git clone https://github.com/HarllonCS/free-market.git
```

2. Open the project folder.

3. Double-click the `index.html` file (or drag and drop it into any modern web browser, such as Chrome, Firefox, or Edge).
